# IRON SPORTS 360º

Protótipo inicial da loja virtual e do painel administrativo em Next.js, TypeScript e Tailwind CSS.

## Executar

```bash
npm install
npm run dev
```

Loja: http://localhost:3000

Painel demonstrativo: http://localhost:3000/admin

## Estado atual

Interface inicial sem integração com banco de dados. Supabase, autenticação, estoque, pedidos, pagamentos e Agilize CRM 360º ainda precisam ser implementados. **Não usar em produção**: a rota administrativa ainda não possui controle de acesso. Não cadastrar dados reais nem incluir credenciais no GitHub.
